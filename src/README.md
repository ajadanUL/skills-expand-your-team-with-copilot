# Mergington High School Activities

A super simple website application that allows students to view and sign up for extracurricular activities.

## Features

- View all available extracurricular activities
- Filter activities by difficulty level; activities without a difficulty are available at every level
- Sign up for activities
- Switch between light and dark mode using the toggle in the top-right corner; your choice is saved in your browser
- Share activities with friends

## Sharing an Activity

At the bottom of every activity card there is a row of **Share** buttons:

| Button | What it does |
| ------ | ------------ |
| **f** (blue) | Opens Facebook so you can post about the activity |
| **𝕏** (black) | Opens X (Twitter) with a ready-made message |
| **💬** (green) | Opens WhatsApp with a ready-made message |
| **✉** (orange) | Opens your email program with a pre-filled message |
| **🔗** (purple) | Copies a message and link so you can paste it anywhere |
The shared message includes the activity name, its schedule, and a link to this website. No personal information (such as student emails) is ever shared.
